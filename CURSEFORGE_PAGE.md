<h1 style="text-align: center;"><span style="color: #55aa55;">🇺🇸 Description (English) 🇺🇸</span></h1>

<p style="text-align: center;"><span style="font-size: large;"><strong>🌟 Turn your spawn into a full experience — without writing a single line of code. 🌟</strong></span></p>

<p>&nbsp;</p>

<p align="center" style="text-align: center; margin-top: 1.2em; margin-bottom: 0.6em;"><span style="font-size: xx-large; color: #55aa55;"><strong>🤔 Why Arcadia Spawn?</strong></span></p>

<table style="margin-left: auto; margin-right: auto; max-width: 950px;">
<tbody>
<tr>
<td style="padding: 12px 16px; vertical-align: top; width: 50%; border: 1px solid #55AA55; text-align: center;">
<p><span style="color: #55aa55;"><strong>🏠 Custom Spawn Dimension</strong></span><br>The <code>arcadia:spawn</code> dimension is fully configurable — biome, flat layers, time lock, mob spawning rules, height, ambient light, ceiling. Drop your players into a controlled hub world.</p>
</td>
<td style="padding: 12px 16px; vertical-align: top; width: 50%; border: 1px solid #55AA55; text-align: center;">
<p><span style="color: #55aa55;"><strong>🚪 Dynamic Lobby Menu</strong></span><br><code>/lobby</code> opens a chest GUI listing every configured warp. Each warp has its own item icon and bilingual description. Add or edit warps live with <code>/arcadia_spawn setlobbytp</code>.</p>
</td>
</tr>
<tr>
<td style="padding: 12px 16px; vertical-align: top; width: 50%; border: 1px solid #55AA55; text-align: center;">
<p><span style="color: #55aa55;"><strong>🎯 Smart RTP</strong></span><br><code>/arcadiartp</code> finds a safe ground position in the Overworld within a configurable radius. Usage cap per player, warmup with movement cancel, cooldown — all tunable. Callable from any dimension.</p>
</td>
<td style="padding: 12px 16px; vertical-align: top; width: 50%; border: 1px solid #55AA55; text-align: center;">
<p><span style="color: #55aa55;"><strong>📋 Themed Tab List</strong></span><br>Configurable header / footer with placeholders, <code>&amp;</code>-style color codes, and 7 built-in animations (<code>scroll</code>, <code>pulse</code>, <code>rainbow</code>, <code>loading</code>, <code>blink</code>, <code>bar</code>, <code>title_color</code>). Refresh rate tunable down to 5 ticks for smooth animations.</p>
</td>
</tr>
<tr>
<td style="padding: 12px 16px; vertical-align: top; width: 50%; border: 1px solid #55AA55; text-align: center;">
<p><span style="color: #55aa55;"><strong>👑 LuckPerms Rank Sorting</strong></span><br>Players are placed into Minecraft teams named <code>as_&lt;999-weight&gt;_&lt;group&gt;</code> so the highest LuckPerms weight always sits at the top of the tab. Without LuckPerms: clean op-level fallback (Owner → Default). Listens to <code>UserDataRecalculateEvent</code> for instant refresh.</p>
</td>
<td style="padding: 12px 16px; vertical-align: top; width: 50%; border: 1px solid #55AA55; text-align: center;">
<p><span style="color: #55aa55;"><strong>👻 Spectator Hide</strong></span><br>Players in <code>/gamemode spectator</code> disappear from the tab list of non-spectators. Other spectators still see each other so co-moderation works. Server-authoritative via <code>ClientboundPlayerInfoRemovePacket</code>.</p>
</td>
</tr>
<tr>
<td style="padding: 12px 16px; vertical-align: top; width: 50%; border: 1px solid #55AA55; text-align: center;">
<p><span style="color: #55aa55;"><strong>🌐 Cross-Server Player Counts</strong></span><br>Every server heartbeats its row into a shared <code>arcadia_tablist_servers</code> table via the arcadia-lib database, reads the others, and renders one footer line per peer with ALIVE / STALE flag. All JDBC async — main thread never blocks.</p>
</td>
<td style="padding: 12px 16px; vertical-align: top; width: 50%; border: 1px solid #55AA55; text-align: center;">
<p><span style="color: #55aa55;"><strong>🗺️ Custom Dimensions On Demand</strong></span><br><code>/arcadia_spawn dimension create &lt;id&gt; [preset] [biome]</code>. Definitions are JSON under <code>config/arcadia/spawn/dimensions/</code> registered at startup under the <code>arcadia_custom:</code> namespace. Presets ship for <code>flat</code>, <code>void</code>, <code>lobby</code>.</p>
</td>
</tr>
<tr>
<td style="padding: 12px 16px; vertical-align: top; width: 50%; border: 1px solid #55AA55; text-align: center;">
<p><span style="color: #55aa55;"><strong>🔐 Slot Bypass</strong></span><br>Permission-based slot bypass. Players with <code>arcadia_spawn.slots.bypass</code> bypass the slot limit when the server is full. Mixin-based fake max-slots in the server list and optional join / leave message hiding.</p>
</td>
<td style="padding: 12px 16px; vertical-align: top; width: 50%; border: 1px solid #55AA55; text-align: center;">
<p><span style="color: #55aa55;"><strong>🛡️ Anti-Corruption Hardened</strong></span><br>Atomic JSON writes via <code>SafeFileIO</code>, 5 rotated backups per file, auto-recovery on load failure. <code>SpawnData</code> validates dimensions, <code>DimensionType</code> clamps heights to vanilla limits. Strict input regex on lobby names and dimension ids (Windows reserved blocklist).</p>
</td>
</tr>
<tr>
<td style="padding: 12px 16px; vertical-align: top; width: 50%; border: 1px solid #55AA55; text-align: center;">
<p><span style="color: #55aa55;"><strong>🌐 100% Bilingual EN/FR</strong></span><br>Every user-facing string flows through <code>LocalizationManager</code> with both English and French translations. Detection per-player via client info — no manual switch needed.</p>
</td>
<td style="padding: 12px 16px; vertical-align: top; width: 50%; border: 1px solid #55AA55; text-align: center;">
<p><span style="color: #55aa55;"><strong>🔑 Soft LuckPerms Integration</strong></span><br>Permission nodes on every admin subcommand and on slot bypass. Weight-driven grade sorting + prefix rendering when LP is installed. Falls back silently to vanilla OP checks when it isn't. Listener subscribes to <code>UserDataRecalculateEvent</code> for live promotion / demotion updates.</p>
</td>
</tr>
